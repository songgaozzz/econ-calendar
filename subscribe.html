⚠️ 微信内置浏览器无法打开日历订阅/下载。请点右上角 「···」 → 「在浏览器打开」，再点下面的按钮。

🟦 安卓 / Google 日历

登录 Google 账号后确认「添加」，日历会同步到手机 Google 日历 App。

添加到 Google 日历 提示“无法添加日历”？试 备用链接，或复制下方链接到 Google 日历网页版「其他日历 ＋ → 通过网址添加」。
  1. 手机上若跳进 App 或页面不完整：浏览器菜单勾选 「桌面版网站」 后再点一次。
  2. 添加后在 Google 日历 App → 设置 → 「全球财经日历」→ 打开 同步。
  3. Google 刷新订阅较慢（常见 12–24 小时）。

🍎 iPhone / iPad / Mac

系统日历直接订阅，自动更新。

iPhone / Mac 订阅
  1. 点按钮 → 弹窗选 「订阅」 → 可改名/颜色 → 完成。
  2. 若没反应：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴下方链接。

📧 Outlook / Microsoft 365

一键打开「从网页订阅」，名称已填好「全球财经日历」，点 导入 即可；手机 Outlook App 会自动同步。

Outlook 订阅（工作/学校 · Microsoft 365） Outlook 订阅（个人 · Outlook.com）
  1. 经典 Outlook（Windows）：日历 → 添加日历 → 从 Internet → 粘贴下方链接。

⬇️ 下载 .ics 导入（一次性）

下载后用手机日历 App 打开导入；这是快照，不会自动更新，建议优先用上面的订阅。

下载 .ics 导入 安卓：下载完成后在通知栏或「文件 / 下载」里点开 econ-calendar.ics → 选日历 App。

🔗 复制订阅链接

适用于任何支持「通过网址订阅」的日历（Google 网页版、Outlook、Thunderbird 等）。
